# Котопульта

Уютная физическая игра по рисунку Паши Гансона: пушка и рыжий кот слева, дуга полёта, рыбки, башня коробок и сонный кот справа. Цель — разбудить соню за три выстрела. Все коты целы, коробки — как получится.

## Запуск в Windows

Из этой папки:

```powershell
.\start.cmd
```

Или из любой папки:

```powershell
C:\ai-tests\napkin\astra\start.cmd
```

Браузер откроется автоматически. Оставь окно запуска открытым; **Ctrl+C** останавливает сервер. Игра работает на `http://127.0.0.1:5188`, только на этом компьютере. Повторный запуск открывает уже работающую игру.

На этом компьютере Node.js уже установлен. Готовая сборка лежит в `dist/`, поэтому для обычной игры интернет и установка пакетов не нужны. Для переноса на другой Windows нужен Node.js 22.12+; достаточно `dist/`, `scripts/launch.mjs` и `start.cmd` с сохранением структуры папок.

## Управление

| Действие | Управление |
|---|---|
| Прицел и сила | Наведи мышь: направление задаёт угол, расстояние от пушки — силу |
| Выстрел | Зажми левую кнопку, уточни прицел, отпусти |
| Мяу-рывок | **Пробел** или клик в полёте; один раз на выстрел |
| Прицел с клавиатуры | **↑ ↓** — угол, **← →** — сила, **Пробел** — выстрел |
| Заново | **R** |
| Пауза | **Esc** |
| Звук | **M** |
| Полный экран | **F**, либо **F11** в браузере |

На сенсорном экране: зажми, наведи, отпусти; повторное касание или кнопка снизу включает рывок. Лучше играть горизонтально. При переключении вкладки игра сама ставится на паузу.

## Как получать звёзды

- Разбуди кота: попади в него, урони его опору или используй рывок рядом.
- Собери хотя бы две рыбки.
- Уложись в один выстрел.

Рывок ускоряет кота вперёд, толкает близкие коробки и собирает рыбок в радиусе. Стеклянные ящики хрупкие, зелёные крепче обычных. На некоторых уровнях есть лёгкий ветер; пунктир уже учитывает его. Последняя траектория остаётся бледным следом для корректировки следующей попытки.

Восемь уровней, до 24 звёзд. Лучшие звёзды, счёт и настройка звука сохраняются в localStorage текущего браузера. Приватные окна имеют отдельный прогресс. Прохождение и звёзды не отправляются на сервер.

## Разработка

```powershell
npm.cmd ci
npm.cmd run dev
npm.cmd run build
npm.cmd test
```

После изменения исходников пересобери игру: `.\start.cmd --rebuild`. Открытую вкладку затем обнови.

Основа: TypeScript, Phaser 3.90 (рисование), Matter.js 0.20 (физика с фиксированным шагом 60 Гц), Vite 7.3.6. Интерфейс на HTML/CSS, оригинальные музыка и звуковые эффекты синтезируются через Web Audio. Фон, шрифты и исходники находятся в проекте; сетевых сервисов в игровом процессе нет.

- `src/game/` — правила, уровни и сохранение.
- `src/render/` — отдельные иллюстрированные объекты, анимация, камера и эффекты.
- `src/audio/` — музыка, мяуканье, выстрелы и попадания.
- `src/ui/` — меню, HUD и управление.
- `tests/` — физические и браузерные проверки.
- `docs/ART.md` — происхождение графики и точный prompt фона.
- `docs/QA.md` — что проверено и где лежат кадры.

Браузерные проверки требуют Chromium. Можно указать путь через `$env:CHROME_PATH`. Скрипты рассчитаны на запущенный локальный сервер. `npm.cmd run test:browser` проверяет основной сценарий; `node tests/campaign.mjs` проходит всю кампанию. Playwright видео не записывает системный звук; отдельный тест `tests/media.mjs` также записывает фактический Web Audio выход.
